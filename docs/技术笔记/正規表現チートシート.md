# 正規表現チートシート

## 基本量指定子

| パターン | 意味 |
|:---|:---|
| `*` | 0回以上 |
| `+` | 1回以上 |
| `?` | 0または1回 |
| `{m,n}` | m〜n回 |

## よく使うパターン

```text
Markdown画像:  !\[[^\]]*\]\([^)]+\)
見出し:        ^(#{1,6})\s+(.*)$
URL:          https?://[^\s<)]+
```

## 先読み・後読み

- `(?<!\w)` 直前が文字でない
- `(?!\w)` 直後が文字でない

強調 `*text*` の判定に使う: `(?<!\w)\*([^*\n]+)\*(?!\w)`
