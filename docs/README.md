# docs 目录

**这里放你的 Markdown 文档树。** 本目录内容不入库（`.gitignore` 忽略），它属于每个使用者自己。

## 怎么用

1. Clone 本仓库后，把你的文档放进 `docs/`：
   ```
   docs/
   ├── 工作手册/
   │   └── 日次業務フロー.md
   ├── 技术笔记/
   │   └── Python標準ライブラリメモ.md
   └── ...
   ```
2. 启动服务：`./run.sh`（默认 127.0.0.1:8850，可用 `--port` 改）。
3. 打开浏览器，侧栏自动按目录树展示你的全部文档。

## 支持的功能

- **目录树浏览**（左侧自动展开/折叠，记忆展开状态）
- **全文搜索**（⌘K，CJK 2-gram 切词）
- **Markdown 编辑**（分屏预览、粘贴截图直传、草稿自动保存）
- **文档管理**（新建/改名/移动/删除、图片资产目录自动跟随）
- **收藏 / 项目高亮**（侧栏顶部 全部/收藏 两个 tab）
- **健康检查**（断链/孤儿图片清理）+ **Git 版本**（历史/恢复旧版/提交）
- **导出 PDF**（文档页右上角按钮）
- 四种主题：纸墨亮/暗 + GitHub Light/Dark

## 图片

插入的图片保存在 `docs/<文档名>_assets/` 目录，随文档移动。

## 端口

默认 `127.0.0.1:8850`（本机访问，安全）。如需局域网访问，`--host 0.0.0.0` 并自加认证。
