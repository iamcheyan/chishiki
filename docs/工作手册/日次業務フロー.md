# 日次業務フロー

毎日の定型業務の流れをまとめています。

## 始業時（9:00）

1. メールボックス確認
2. 前日タスクの棚卸し
3. 今日の予定をチームチャンネルに共有

## 終業時（18:00）

- [ ] 日報の作成と提出
- [ ] 明日のタスク優先順位付け
- [ ] デスクトップのファイル整理

!> **注意** 日報の提出忘れはチームKPIに影響します。リマインダーを設定すること。

## トラブル時のエスカレーション

| 状況 | 担当 | 連絡方法 |
|:---|:---|:---|
| 軽微な遅延 | リーダー | チャット |
| 顧客影響あり | 部長 | 電話+メール |
| システム障害 | 運用チーム | 緊急連絡網 |

詳細は[システム運用](システム運用/README.md)を参照。
