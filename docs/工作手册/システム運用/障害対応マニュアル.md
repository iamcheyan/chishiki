# 障害対応マニュアル

## 重大度定義

| レベル | 定義 | 目標復旧時間 |
|:---:|:---|:---:|
| S1 | 全サービス停止 | 1時間 |
| S2 | 一部機能障害 | 4時間 |
| S3 | 軽微な不具合 | 3営業日 |

## 復旧手順

```bash
# サービス状態確認
systemctl status app

# ログ退避
journalctl -u app --since "1 hour ago" > /tmp/incident.log

# 再起動
sudo systemctl restart app
```
